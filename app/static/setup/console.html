API Budget, Limits & Stats

Game API budget: outbound calls per minute to the BYM servers, priority-scheduled (1 lowest, 10 highest; strict - low priorities wait while high ones stream). The global limit covers all users combined; the per-user limit stops one person's browsing from eating the whole budget without blocking anyone else. Queue depth bounds how many requests may wait for budget (beyond it they are rejected instantly with a retry hint); max wait is how long a queued request may park before giving up. Raise the global limit temporarily before a world scan.

Viewer endpoints: this server's own request limits (map reads, alliances, everything except the game-API budget above). Sustained per minute plus a burst allowance, per signed-in user or per anonymous IP.
